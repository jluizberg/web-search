# Dashboard

React + Vite admin UI for managing authors, targets, topics, and viewing articles.

## Status

Planned — not yet implemented.

## Planned pages

- `/authors` — list, add, edit, delete authors
- `/targets` — list, add, edit, delete search targets
- `/topics` — list, add topics
- `/articles` — list, filter by topic/author/site, view details

## Tech stack

- React 18
- Vite
- React Router
- Axios for API calls

## Running

```bash
cd services/dashboard
npm install
npm run dev
```

## Building

```bash
npm run build
```

Output goes to `services/dashboard/dist/`.
